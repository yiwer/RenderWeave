# RenderWeave Web

React/Vite client skeleton. The only current route is a **throwaway UI prototype**, not production Schema functionality:

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

Open `/prototype/schema-studio?variant=A`, then compare `A`, `B`, and `C` with the development-only bottom switcher or keyboard arrow keys. Once a direction is approved, record the decision, remove losing variants and implement the selected structure under production constraints.

The supported project baseline is Node 24 LTS. A build under another Node version is compatibility evidence only.
