## 目标

基于 Flash/Plus 两轮 60-case evidence，修正 Prompt v1 的字段身份错误并降低 Plus 的多建 Schema/字段/边与不确定性越界；不覆盖 v1，不降低认证阈值。使用新的精确 J1 完成 Prompt v2 的 60-case live 复验，并按原认证政策如实保留 `EXPERIMENTAL`。

## 归因基线

- Plus 51 critical = 6 unexpected entities + 31 unexpected fields + 6 unexpected edges + 8 unsupported assertions。
- Plus 相对 Flash 明显减少 missing entity/field/edge 与 provider failure，但 supported type 仍有 22 个未命中；因此本轮优先“最小证据图 + JSON truth table + exact FieldKey”，而不是换模型或增加 repair 次数。
- 高影响 case 集中在 image object-array/multiple-images、JSON empty/nested/heterogeneous array、object-scalar conflict、Unicode 与 JSON Pointer escaping。
- 详细决定与非目标见 ADR-0010。

## 独立复核处置

首次独立 pre-live A2 复核结论为 FAIL，阻断项是 provider 可伪造人工处置、JSON evidence 未绑定真实 structural location，以及 parseable validator blocker 无法到达 REPAIR。增量复核进一步发现并阻断：repairable/human blocker 混合时可能绕过人工边界、低置信 `NOT_REQUIRED` 可被 evaluator 误认证、COMBINED 可用 IMAGE evidence 替代必需 JSON evidence、catalog membership 的重复全表扫描，以及不可表示的 exact JSON key 可能被模型删除或改名。上述项均已按 ADR-0010 的三态路由、evaluator contract/critical、JSON missing、反向索引与 FieldKey 人工边界修复并由失败测试转绿，最终 pre-live A2 为 PASS。

完成后独立 reviewer 又从 journal 和 60 个 payload-free CaseResult 重新聚合全部 global/mode/partition metrics，逐条重算 70 次 reservation、token、价格、时间线预算、16 批次、identity/lifecycle 与泄露扫描，结论仍为 PASS，未发现 Blocker / High / Medium。19 个 evidence/log 文件中 key、Bearer、provider request id、Candidate/prompt/task/RootDocument payload、data URI、长 Base64 与 chain-of-thought 均为 0 命中。该证据为本地 A2，不是受外部不可变存储保护的 A3；因设计上不保留 Candidate 原文，不能从原始输出重新运行 evaluator。

## 验收边界

本轮 live 证明 Prompt v2 有明显方向性提升，但没有通过 `critical=0` 等认证阈值。该 Profile 继续为 `EXPERIMENTAL`、默认关闭；authorization 已 `CLOSED`，后续任何 live 调用必须使用新的 Profile/identity/evidence 与新的精确 OPEN 生命周期，不能继承本轮剩余预算或时间。
