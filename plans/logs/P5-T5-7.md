## 目标

基于 Flash/Plus 两轮 60-case evidence，修正 Prompt v1 的字段身份错误并降低 Plus 的多建 Schema/字段/边与不确定性越界；不覆盖 v1，不降低认证阈值，不在新的精确 J1 前调用 DashScope。

## 归因基线

- Plus 51 critical = 6 unexpected entities + 31 unexpected fields + 6 unexpected edges + 8 unsupported assertions。
- Plus 相对 Flash 明显减少 missing entity/field/edge 与 provider failure，但 supported type 仍有 22 个未命中；因此本轮优先“最小证据图 + JSON truth table + exact FieldKey”，而不是换模型或增加 repair 次数。
- 高影响 case 集中在 image object-array/multiple-images、JSON empty/nested/heterogeneous array、object-scalar conflict、Unicode 与 JSON Pointer escaping。
- 详细决定与非目标见 ADR-0010。

## 独立复核处置

首次独立 A2 复核结论为 FAIL，阻断项是 provider 可伪造人工处置、JSON evidence 未绑定真实 structural location，以及 parseable validator blocker 无法到达 REPAIR。增量复核进一步发现并阻断：repairable/human blocker 混合时可能绕过人工边界、低置信 `NOT_REQUIRED` 可被 evaluator 误认证、COMBINED 可用 IMAGE evidence 替代必需 JSON evidence、catalog membership 的重复全表扫描，以及不可表示的 exact JSON key 可能被模型删除或改名。上述项均已按 ADR-0010 的三态路由、evaluator contract/critical、JSON missing、反向索引与 FieldKey 人工边界修复并由失败测试转绿。最终独立 A2 复审为 PASS，未发现剩余 Blocker / High / Medium；复核全程不读取 key、不调用 provider、不修改工作树。

## 验收边界

离线门控只能证明 prompt/profile/contract/诊断实现一致，不能证明模型质量提升。未来 live 复验仍使用完整 60-case corpus、每批最多 5 case、critical=0 的原认证政策，并使用新 Profile、独立 identity、独立 evidence 目录与立即 CLOSED 生命周期。
