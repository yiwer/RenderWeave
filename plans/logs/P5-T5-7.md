## 目标

## 归因基线

- Plus 51 critical = 6 unexpected entities + 31 unexpected fields + 6 unexpected edges + 8 unsupported assertions。
- Plus 相对 Flash 明显减少 missing entity/field/edge 与 provider failure，但 supported type 仍有 22 个未命中；因此本轮优先“最小证据图 + JSON truth table + exact FieldKey”，而不是换模型或增加 repair 次数。
- 高影响 case 集中在 image object-array/multiple-images、JSON empty/nested/heterogeneous array、object-scalar conflict、Unicode 与 JSON Pointer escaping。
- 详细决定与非目标见 ADR-0010。
