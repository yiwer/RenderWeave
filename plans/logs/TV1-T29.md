## 产品增量

1. 新增 Editor-owned save transport，直接以已验证 decimal token 构造 lossless int64 `expectedRevision` query，并以
   `application/vnd.renderweave.design+json` 发送 exact canonical UTF-8。clean、max signed-long revision 或 mutation
   非 idle 时不产生 I/O；不依赖把 int64 映射为 JS `number` 的 generated SDK。
2. save coordinator 将 PUT 发起样本绑定到 expected revision、draft canonical 与 preview generation。请求期间锁定本地
   edit/undo/redo/save；只有 READABLE 200 且 content hash、template identity、permanent StaticSchema、exact canonical、
   expected+1 revision 与 `READY | INVALID` readiness 全部通过，才采用新 immutable baseline 并清空 history/generation。
3. 只有 409 + `TEMPLATE_REVISION_CONFLICT` + lossless current revision 生成 overwrite offer；offer 绑定远端 revision、
   draft canonical 与 generation，任何 edit/undo/redo 都使其失效。确认后先 GET trusted current；漂移时只更新 offer 并
   要求重新确认，无 PUT；revision 相同时才 PUT，第二次 409 仍要求新确认，GET unavailable 安全保留 offer。
4. PUT network、500/503、malformed 或不一致 2xx 进入真实 outcome-unknown mutation lock：保留 draft，不谎报失败、
   不盲重试、不替换 baseline，也不暴露 retry/adopt/reconcile 动作。400/401/403/404/409-other/410/413/415/422 为已知
   no-write rejection，有限显示 code/message 并保留 dirty draft。
5. Canvas Focus shell 接入真实 save/pending/conflict/reconfirm/cancel/rejected/unknown 状态，提供 polite/alert 语义和真实
   disabled controls；成功后显示新 revision，conflict 按钮明确目标 revision。视觉沿用锁定 `design.md`，无装饰动画或
   全局 z-index。
6. 组件仍未挂载 `/templates/:templateId`；没有 E4 dependency confirmation/problem projection、E5 reconciliation、
   E6 preview、E7 recovery、E8 import、E9 完整 accessibility、Asset picker 或相应 future placeholder。
