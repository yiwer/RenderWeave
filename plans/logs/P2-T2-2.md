## 关键结果

- 所有 active 图变更在同一 PostgreSQL transaction 内先取得常量 advisory lock，再解析目标、替换拟议出边并检查 cycle/depth；并发 `alpha→beta` / `beta→alpha` 只能提交一边。
- 根计 1 的 depth 16 接受、17 拒绝；missing/self/cycle 均在 revision/edge 写入前失败。
- edge 是 revision DSL 的同事务 projection：保存/删除停用旧 active 出边，历史 edge 与 immutable revision 保留。
- active incoming Draft reference 返回稳定 blocker summary；删除后 key 保留且不可复用。
- restore 把选定历史 definition 复制成新 revision；目标失效时零写并保持 deleted，目标恢复后可重试成功。
- copy 只复制观察到的 current definition/field order/constraints/refs，要求 source revision 未变化，新 Draft 为 USER revision 0。
- OpenAPI 升至 0.3.0，覆盖七类型 DSL、revision history/copy/delete/restore 与 `resolvedRevisions`；生成客户端通过 Node 24 gate。
