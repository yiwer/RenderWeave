## 失败探针与恢复

- 首次 focused architecture 命令因 PowerShell 5.1 把未加引号的 `-Dsurefire...` 拆为 Maven lifecycle token，
  Maven 在测试前退出；改用显式 quoted JVM properties 后执行真实测试。
- 首次真实 architecture replay 为 3/4：synthetic native fixture 是单行文本，而 guard 当时只匹配行首。
  将 fixture 改为合法多行 method declaration并收紧 declaration regex 后为 4/4；真实树的三个规则始终通过。
- 首次完整 server evidence `.sdlc/evidence/20260817-202215-server/` 在 app 前失败：65 errors/8 assertions
  全部根因是 `SOURCE_INVENTORY_DRIFT`。只读 hash 对照证明 LF blob 转 CRLF 后精确等于冻结 manifest，故未
  重写 manifest/identity/Inference code；增加 exact checkout attributes 并从头重跑，最终 server 全绿。
- EOL refresh 只作用于两个已验证无用户 diff 的 tracked legacy resource；Git index 中内容仍为 LF，工作树按
  新 attribute 为 CRLF。操作可通过回退本票 `.gitattributes` 行恢复，没有数据库或外部副作用。
