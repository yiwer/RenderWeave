## 产品增量

1. 在既有 workspace-internal `renderweave-renderer-layout` deep module 中新增唯一 arrange seam
   `layout_definite_absolute(&AdmittedRenderDocument)`；调用方仍必须先跨过 T23 admission，入口与 T25 共用
   同一次 parse/preflight，返回 immutable authored-preorder `DefiniteLayout` 或 closed internal error。
2. 根 Canvas 的 LayoutBox/ContentBox 为 `(0,0,widthPt,heightPt)`；Canvas/Frame ContentBox 下只接纳
   ABSOLUTE `FIXED | FILL` 的 Frame 与 `rect | ellipse | line | polygon | polyline | path | qrCode | barcode`。
3. FIXED 使用 authored size；FILL 以固定 binary64 顺序执行 `(parent - start) - endInset`、非正 remainder
   归一为正零，再依次应用 min/max。位置为 parent ContentBox origin + authored x/y，不引入 epsilon、量化、
   `mul_add` 或未冻结 tolerance。
4. Frame ContentBox 逐项扣除双侧 inward stroke，再按 top/right/bottom/left padding 扣除；任一步小于零返回
   `DEGENERATE_CONTENT_INSET`。普通 transform 明确不反馈 pre-transform local box。
5. HUG、Group、Stack、Grid、compositionViewport、Text/Image、非 ABSOLUTE 与退化 inset 使用 8 个稳定 closed
   internal unsupported feature，不映射 public render problem、不返回 partial layout。
6. `render` gate 升至 `renderweave-renderer-process-gate/1.3`，新增独立 definite-layout report和 frozen
   count/boundary assertions；daemon/process manifest、HELLO、capability inventory 与 Profile registry不变。
