## 关键结果

- editor state 覆盖 text、decimal、date、time、boolean、reference、array；array item 使用同一 scalar/reference grammar 且类型上排除 nested array。
- 所有 optional constraint 显式保存 enabled/value，因而能区分 absent 与合法空 text const；enum 保留输入顺序。
- `rowKey` 只服务内存 occurrence 与 React identity，序列化和 dirty semantic fingerprint 均显式排除，正式字段身份仍是 `schemaKey + fieldKey`。
- history 只记录语义 checkpoint；view switch、selection 不入栈；相同 historyGroup 的连续 typing 合并，其他 action/blur 可结束组。
- undo/redo 各有上限 100；add/duplicate/delete/reorder/type/value/meta 都走同一 reducer，恢复后保持可用 selection。
- save success 更新服务端 normalized snapshot 与 saved baseline，但不清空 undo/redo；reload 清空；restore saved 是可 undo 的语义 action。
- 首次 create 后历史中的 schemaKey 被锁为真实 identity，避免 undo 产生“revision 已存在但 key 为空/可改”的非法 session。
- `lossless-json@4.3.0` 只用于 definition 边界；128 位 decimal lexeme round-trip 仍输出未加引号 JSON number，避免 generated JS `number` 静默精度损失。
