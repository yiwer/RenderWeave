## 关键结果

- compiler 输出 JSON Schema 2020-12 的稳定紧凑字节，不产生 `$ref`/`$defs`；引用 child artifact 按叶到根完全内联，并保留各 child 的 compiler version。
- `date` 映射 ISO `YYYY-MM-DD`，`time` 映射 `HH:mm:ss`；decimal 使用无指数 plain number，约束与字段顺序稳定。
- 发布只接受当前 active Draft 的精确 revision；Draft 引用会阻断发布，Static 引用必须精确到 `schemaKey + versionTag`。
- 相同 Draft revision 可发布多个 versionTag；Static identity 唯一，既有 artifact 不因 Draft 后续变化而重算。
- artifact UTF-8 超过 2 MiB 时整次发布回滚；故障注入证明 row、reference edges 与 artifact 零部分写入。
- 安装 `system-empty@v1` 与 text/decimal/date/time/boolean 五个基础预置；预置 DSL 和保存的 artifact 与当前 compiler byte-for-byte 一致。
- Static API 只提供 list/read/definition/artifact/copy/publish，不暴露 update/delete/recompile；artifact 以 `application/schema+json` 原样返回。
- Draft 引用图已统一处理 Draft/Static 混合依赖深度；root 计 1，16 接受、17 拒绝。

## 重要取舍

- Static artifact 使用 PostgreSQL `json` 保存精确文本，而 DSL snapshot 使用 `jsonb`；读取 artifact 不重新序列化。
- 没有 hash、closure table 或数据库 immutability trigger；不可变性由 append-only application/repository surface 与 API 合同保证，数据库只保留 PK/unique/FK/check。
- Flyway 关闭 placeholder replacement，避免系统预置的 dollar-quoted JSON 被误解释；迁移仍是唯一建表入口。
- Web 生产 bundle 当前约 508 kB，构建只是 warning；P3 路由与编辑器拆包时处理，不作为本任务失败。
