## 可验证增量

1. 新增确定性的多尺度视图规划器。每个源图先生成 overview，再按稳定顺序生成 targeted crop 与 tile；总视图
   不超过 10、总字节不超过 30 MiB。Provider 只看到内存视图，checkpoint、Candidate 和证据只保留原始
   artifact 坐标，不持久化派生图。
2. 视图坐标通过有理数 floor/ceil 规则映射回原图 0..10000 坐标；未知尺寸继续使用 4096² 保守费用上界，
   已知视图尺寸则按实际 patch 数预留，避免多尺度引入不必要的成本放大。
3. 新增 `renderweave-visual-grounding/2.0` region forest，以及 hierarchy/binding 2.0 的实体和关系空间归属。
   服务端确定性拒绝越界、孤儿、环、深度超限、兄弟阅读顺序断裂、同层重叠、重复组漂移、证据越界和
   element/entity/binding 归属不一致。
4. checkpoint 升级到 3.0，仍可读取 1.0/2.0；pipeline 4.1 在崩溃恢复时从原始 Blob 确定性重建派生视图，
   不重复已完成阶段，也不把 view id 泄漏到最终 Candidate。
5. 新增 Flash、Plus、Max 各两份隐藏 v6 Profile：GENERIC 与显式 TRANSIT_BOARD。通用核心 Prompt 不包含
   公交、站牌、线路、站点、票价等领域词；公交知识只存在于显式 hint pack，避免用单一领域提示污染菜单、
   价签等跨域输入。
6. 历史 v1..v5 Profile/Prompt 资源字节未修改；新增 nullable Profile 字段只在 v6 序列化，旧 canonical
   snapshot hash 保持不变。v6 仍为内部 `EXPERIMENTAL`，未进入产品选择器。
