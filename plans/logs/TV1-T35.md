## 产品增量

1. 新增 Web-owned `template-recovery` deep module，以 `renderweave-template-local-recovery/1` 管理当前设备每个
   Template 至多一份的 localStorage recovery record。parser 拒绝 unknown member，在装载前复核 permanent identity、
   base revision/content hash、exact canonical draft/domain hash、preview generation、最小 UI state、timestamp 与可选
   E5 unknown attempt，随后深冻结恢复对象。
2. dirty working copy 以固定 500ms debounce 替换同一 key，`beforeunload` 只做同步 best-effort；成功 save/adopt、
   undo 回 clean 或显式 discard 清理记录。恰好 7 天仍有效，超过 7 天读取即清理；quota/privacy/storage failure
   如实投影，不把浏览器存储冒充持久性承诺。
3. 普通记录不会自动采用：作者只能显式恢复、导出 exact bare DesignDSL 或放弃。baseline drift 持续显示旧/新
   revision，具名确认后才恢复；恢复 session 清空 history，首次 save 仍走既有 overwrite offer/confirm，避免以最新
   revision 静默覆盖。
4. E5 attempt observer 在 PUT 前 best-effort 立即写入 exact attempt；刷新后严格重建锁定 session 并自动执行只读
   trusted-current reconciliation，复用 adopted/retryable/conflict/deleted/fail-closed 分类，绝不自动重发 PUT。
   remote DELETED 不删除未保存草稿，仍保留 export。
5. 持久化面不包含 RootDocument、customValues、preview image、Asset bytes、RenderDocument、sidecar、lease 或其他
   runtime input；没有服务端 autosave/Patch、跨设备同步、Java/API/migration/route 增量。
