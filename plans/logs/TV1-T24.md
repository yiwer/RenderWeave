## 产品增量

1. 新增 workspace-internal `renderweave-renderer-output-png` deep kernel。`preflight_surface` 只接受 T23
   canonical decimal6 pt 与 effective integer DPI，以 checked `i128` 对 trim+两边 bleed 整体执行一次
   `ROUND_HALF_UP(... × dpi / 72)`，不使用 binary float、逐边 rounding 或 pixel snapping。
2. preflight 在 allocation 前执行冻结容量：DPI 600、edge 16,384、surface 50,000,000 pixels、RGBA8
   200,000,000 bytes、encoder scratch 67,108,864 bytes、encoded image 536,870,912 bytes；同时精确预测
   raw scanline、stored-block、zlib、IDAT overhead 与最终 PNG byte length。
3. `encode_straight_rgba8` 接受 exact row-major straight RGBA8，拒绝长度错误与 alpha=0/RGB非零；输出固定
   `signature → IHDR → sRGB → pHYs → IDAT+ → IEND`、filter 0、zlib `78 01`、65,535-byte stored block、
   1,048,576-byte IDAT payload、Adler-32 与 PNG CRC。编码直接写入唯一预留结果 buffer，不复制完整
   filtered/zlib surface。
4. 新增 closed shared manifest 与标准库 Python independent verifier；`render` gate 升至 1.1，硬断言 exact
   case/check counts、hash、输出 Profile identity 与诚实未接线边界，并在 Windows Rust workspace及 pinned
   no-network Linux Docker 中重放。
5. workspace Cargo.lock 变化按既有 machine-manifest 合同传播至 process manifest 与 HELLO vectors；没有新增
   process capability、Profile 或 daemon success path。
