## 产品增量

1. root reactor 新增真实 `renderweave-template` artifact。该 artifact 当前无仓库内部 dependency；只有 Jackson
   core 供 internal strict parser 使用，没有提前声明 ADR-0041 允许但尚未实际消费的 Schema/Asset edge。
2. 唯一 public top-level Interface 是 `DesignDslAuthority.admit(byte[] rawUtf8)`；返回 closed
   `Admitted`/`Rejected` union。canonical bytes 防御性复制，failure code/stage/JSON pointer/optional limit 均为
   closed type；全部 Implementation 和 JSON model 位于 `.internal`。
3. minimal admission 只覆盖 exact DesignDSL/Expression versions、root metadata、empty definitions、唯一 Canvas、
   width/height、optional displayName/uppercase RGBA/complete bleed 及 empty bindings/children。non-empty set-like
   arrays 与 semantic children 统一 fail closed，不猜测 Definition/Binding/Node wire，也不注册 partial Profile。
4. parser 在 modeling 前实施 strict UTF-8/no-BOM、strict JSON/no duplicate/no null 与九个冻结 budget；错误按
   parse/semantic/canonical-count stage 收口。first-error traversal 使用 encounter order，bleed required field 使用
   fixed order，避免 JVM collection iteration 导致 pointer 漂移。
5. canonical writer 按 unsigned UTF-8 排 object member，保留支持范围内 array order和非 metadata Unicode，
   canonical arbitrary-precision decimal/`-0`，且不展开业务 default。先通过 16 MiB capped counting sink，再
   分配 exact bytes；content hash 为 domain-separated SHA-256。
6. ADR-0041 的 non-empty ArchUnit anchors 和 public-surface reflection 锁定 API/internal ownership、唯一 Interface、
   sealed/enum/record shape，并禁止 app/Spring/JDBC/native/process dependency。本票无 outbound SPI，故没有可
   合法创建的 scripted Adapter；全部行为测试经正式 `admit` Seam 驱动真实 Implementation。

## TDD 失败探针

- 初始 public Interface test 先因 API/Implementation 不存在而 compile RED；随后最小 baseline 转绿。
- illegal UTF-8、bleed、global null、raw limit、object-member limit 与 canonical-count limit 各自先产生可观察
  failure，再加入对应最小实现。
- 首轮完整 vector replay 抓到 Jackson 3 duplicate message 漂移：旧文本判断误分类为 JSON invalid。改为
  parser-owned duplicate detection，不依赖英文异常消息。
- 第二轮抓到 `Map.copyOf` 不保证 iteration order，使 first unknown pointer 漂到 `/m839`；改为不可变
  `LinkedHashMap` encounter order，而 canonical writer 仍独立排序 object keys。
- ArchUnit 首轮正确揭示 nested record 的 classfile `public` modifier；规则收窄到 externally reachable top-level
  public surface，保留 non-empty internal anchor，随后 8/8 architecture/public-surface tests 绿色。
- non-Canvas kind 与 incomplete bleed vectors 再次先红，最终固定为 value error 与
  `/designRoot/bleed/topMm` deterministic pointer。
