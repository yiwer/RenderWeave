## 产品增量

1. 新增 Web-owned `template-import` deep module，以单一 `Uint8Array` 边界执行 fatal UTF-8/no-BOM、strict JSON、
   全层 duplicate-key、Unicode scalar 与九项冻结预算；decimal 无损转 plain form、`-0` 归零、metadata/set-array
   normalization、unsigned UTF-8 member ordering、16 MiB canonical cap 与 domain-separated SHA-256 均与 Java
   canonical authority 的 46 个 ADMITTED vectors 字节一致。
2. 接受 bare DesignDSL 与 exact closed `renderweave-template-revision-export/1.0`。revision 支持完整非负 signed-int64
   范围（含 0），envelope/hash/UUID/StaticSchema display identity 严格核验；文件 identity/schema 只显示，永不覆盖当前
   Template、永久 StaticSchema 或原 server baseline。
3. 当前 exact pair 且 closed wire 全部可理解进入 Structured；已知 wire 上的语义无效内容仍作为 best-effort local
   draft，交由既有保存权威判定。非法/超限/不可信输入进入 Raw Repair；可信 exact pair 的 unknown member/union
   进入 Compatibility Read-only 并保留 exact 原始 bytes，不 partial reserialize。
4. Structured adoption 不 PUT：候选绑定 target identity、baseline 与 preview generation；采用时清 history、递增
   generation，并继续锚定原 baseline/readiness。dirty working copy 必须明确选择 save、export、discard 或 cancel；
   pending/unknown/reconciliation/conflict/recovery offer 期间锁定，same-working-copy no-op 不清 history 或 recovery。
5. Raw Repair 对合法 UTF-8 提供文本修复、重新检查、原始 bytes 与当前修复稿下载、换文件及丢弃；非法 UTF-8
   保持 byte-only。Compatibility 只显示安全 metadata/reason、exact export、换文件和丢弃；没有 registered migration
   profile，因此不渲染伪 migration action、Structured tree、preview 或 save。
6. 所有下载经可注入 `TemplateEditorDownload` bytes/media-type/filename seam；默认浏览器实现只创建短生命周期
   Blob/object URL。未新增 Java、OpenAPI、generated SDK、migration、API version、产品 route 或 Renderer 行为，
   raw import bytes 不进入 Local recovery。
