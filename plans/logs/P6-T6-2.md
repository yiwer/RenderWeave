## 用户可完成的产品旅程

- `/inference` 将准备输入、受控识别、逐项校对、原子创建组织为连续四步。Replay 可直接进入
  审核；Live 选择只做本地文件队列和 MIME/大小/模式预检查，部署外发门关闭时不会提交。
- 最近识别任务来自服务端持久列表；FAILED/CANCELLED 只能显式创建带 lineage 的新重试任务。
  cancel 有二次确认，SSE、跨标签 apply/cancel 与刷新都会同步同一个 run cache。
- Candidate Form/Map 共用 reducer；支持新增、移除、恢复、上下排序 Schema/field，编辑 key、
  类型、必填、类型专属 constraints、reference 与 array item。根 Candidate Schema 在 UI 和 reducer
  两层均不可移除；没有 confirm-all。
- Evidence 可逐张查看图片及各自 bbox，并独立展示 JSON sample/pointer；AI provenance、confidence
  和原始 evidence 不会被人工编辑伪造。自动保存稳定且 blocker 为零后才开放 create-only 原子创建。
- 1440/1280 保持三栏审核；≤1180 且 ≥1024 使用 Radix 侧滑 Inspector，支持焦点约束、Esc、
  关闭回焦与纯键盘编辑；1180/1181/1200/1260 breakpoint 均有边界回归。低于 1024 明确不支持。
